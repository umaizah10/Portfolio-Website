# THE IDEA ENGINE — Umaizah Azam

A static, machine-world portfolio built with HTML, CSS and JavaScript only.

## Open and deploy

1. Extract the ZIP.
2. Open `index.html` in a browser, or upload the **contents** of this folder to your Heuser GitHub repository under `CS_CRP/Homework_8/`.
3. In GitHub, open **Settings → Pages** and deploy from the branch/folder that contains these files.
4. Open the published `.../Homework_8/` URL and test the controls.

All internal paths are relative. Fonts, images, CSS, JavaScript and the favicon are included locally. The site also works from a locally opened `index.html`; a local preview server is only a convenience.

There is no traditional header, footer, navbar or sidebar. The repeated control surface is a set of physical-looking machine components with real HTML `href` links.

## Interactions

- One short power-on sequence per browser session on Home, with a skip button.
- Rotating gears, a moving piston, blinking indicators and an identity scan beam.
- A three-stage “Run the idea cycle” control.
- Skill-bank, achievement-channel and blueprint-sheet selectors.
- Native project inspection dialogs with Escape/backdrop closing.
- A contact form that opens a `mailto:` draft.
- Copy-email control with a fallback.
- Smooth internal page transitions and a persistent motion toggle.
- Reduced-motion preference is respected by default.

## Concept text on the website

The Idea Engine turns my portfolio into an interactive machine, with each physical control opening a different part of my story. Instead of a conventional menu, visitors operate switches, scanners and terminals to move between separate pages. It is unconventional because the interface makes exploration feel like bringing a creative system to life.
